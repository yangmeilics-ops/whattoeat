# 今天吃什么 🍚

选择困难症救星：一个**纯本地**的微信小程序，摇一摇决定这一餐吃什么。无后端、无第三方依赖，数据全部存在手机本地。

## 功能

- 老虎机式随机选菜，按早餐 / 午餐 / 晚餐 / 夜宵分组，打开自动定位当前餐次
- 110 道内置菜品；⭐ 收藏的菜出现概率 ×3
- 自定义菜品：首页右上角「＋」随时添加，支持一次粘贴多个（空格 / 逗号 / 换行分隔）
- 摇出不想要的结果？「🙅 不想吃」一键排除并立刻再摇
- 菜库管理页：增删自定义菜、隐藏内置菜、收藏 / 排除
- 结果一键复制菜名，方便去外卖 App 搜索；支持分享给好友
- 历史记录（最近 100 条），可一键清空

## 使用

1. 打开「微信开发者工具」→ 导入项目 → 选择本目录
2. AppID 没有就选「测试号」；有的话把 `project.config.json` 里的 `appid` 换成自己的
3. 编译运行即可

## 目录结构

```
├── app.json / app.js / app.wxss     全局配置与样式
├── data/dishes.js                   内置菜品库（早/正餐/夜宵三池）
├── utils/store.js                   本地存储、加权随机、历史记录
├── components/add-dish/             「加个想吃的」弹窗组件
├── pages/index/                     首页：摇一摇
├── pages/dishes/                    菜库管理
├── pages/history/                   历史记录
├── images/                          tabBar 图标
└── tools/gen_icons.py               图标生成脚本（python3 tools/gen_icons.py）
```

## 本地存储 key

| key | 内容 |
| --- | --- |
| `wte_custom_dishes` | 自定义菜 `{id, name, meal}` |
| `wte_dish_flags` | 对某道菜的收藏 / 排除 / 隐藏标记 |
| `wte_history` | 摇出的历史记录（上限 100 条） |
